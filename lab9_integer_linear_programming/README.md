# ЛР9. Целочисленное линейное программирование

Модуль решает задачи целочисленного линейного программирования методом ветвей и границ. LP-релаксации решаются встроенным двухфазным симплекс-методом.

## Возможности

- задачи на максимум и минимум;
- ограничения `<=`, `>=`, `=`;
- типы переменных `integer`, `binary`, `continuous`;
- метод ветвей и границ;
- симплекс-метод для LP-релаксаций;
- отсечение узлов по недопустимости, неограниченности, границе и целочисленности;
- ограничение максимального количества узлов через `max_nodes`;
- точные вычисления через `fractions.Fraction`;
- Markdown-протокол дерева ветвления и симплексных таблиц.

## Формат JSON

```json
{
  "objective": {
    "type": "max",
    "coefficients": [3, 2]
  },
  "variable_names": ["x1", "x2"],
  "variable_types": ["integer", "integer"],
  "constraints": [
    {
      "name": "resource_1",
      "coefficients": [2, 1],
      "sign": "<=",
      "rhs": 7
    }
  ],
  "max_nodes": 1000
}
```

Типы переменных:

| Тип | Смысл |
|---|---|
| `integer` | неотрицательная целочисленная переменная |
| `binary` | бинарная переменная 0 или 1 |
| `continuous` | непрерывная переменная, по ней ветвление не выполняется |

## Вариант 17

Вариант 17 использует интервальные переменные прибыли:

```text
A_0_40, A_40_100, A_100_150, A_over_150
B_0_50, B_50_100, B_over_100
C_0_100, C_over_100
```

Они обозначают части выпуска продуктов `A`, `B`, `C`, попадающие в соответствующие интервалы прибыли.

Целевая функция:

```text
F = 63.2*A_0_40 + 54.4*A_40_100 + 48.3*A_100_150 + 42.1*A_over_150
  + 36.5*B_0_50 + 24.3*B_50_100 + 18.7*B_over_100
  + 30.5*C_0_100 + 24.8*C_over_100 -> max
```

Ограничения:

```text
1.1*A + 2.3*B + 1.3*C <= 120
12.3*A + 4.2*B + 5.1*C <= 640
3.1*A + 2.4*B + 1.2*C <= 450
A_0_40 <= 40
A_40_100 <= 60
A_100_150 <= 50
B_0_50 <= 50
B_50_100 <= 50
C_0_100 <= 100
```

Все исходные производственные переменные являются целочисленными.

## Результат варианта 17

Программа получает оптимальное целочисленное решение:

```text
A_0_40 = 40
B_0_50 = 31
C_0_100 = 3
остальные интервальные переменные = 0
Fmax = 3751
```

В исходных продуктах:

```text
A = 40
B = 31
C = 3
```

Проверка ресурсов:

```text
1.1*40 + 2.3*31 + 1.3*3 = 119.2 <= 120
12.3*40 + 4.2*31 + 5.1*3 = 637.5 <= 640
3.1*40 + 2.4*31 + 1.2*3 = 202 <= 450
```

## Как читать протокол ветвей и границ

1. Корневой узел решает LP-релаксацию без целочисленности.
2. Если решение дробное, выбирается дробная целочисленная переменная.
3. Создаются две ветви:

```text
x <= floor(x*)
x >= floor(x*) + 1
```

4. Каждая дочерняя ветка наследует все ограничения родителя и добавляет свое новое ограничение.
5. Узел отсекается, если он недопустим, неограничен, хуже текущего целочисленного рекорда или уже целочисленный.

В текущем варианте первая LP-релаксация имеет дробные значения `B_0_50` и `C_0_100`. Программа может ветвиться по любой дробной переменной; в протоколе первым выбрано `C_0_100`.
