# ЛР4. Транспортные задачи

Модуль решает транспортные задачи: строит начальный допустимый план, затем оптимизирует его методом потенциалов.

## Возможности

- закрытые и открытые транспортные задачи;
- автоматическая балансировка фиктивным поставщиком или потребителем;
- методы начального плана: `north_west`, `least_cost`, `vogel`;
- оптимизация методом потенциалов;
- построение циклов перераспределения;
- точные вычисления через `fractions.Fraction`;
- Markdown-снимки начального плана, потенциалов, оценок и улучшений.

## Запуск

Из корня проекта:

```bash
python main.py -n 4 -i lab4_example.json -o results/lab4.md
```

Из каталога модуля:

```bash
python main.py -i examples/lab4_example.json -s transportation_snapshot.md
```

## Формат JSON

```json
{
  "initial_method": "vogel",
  "source_names": ["A1", "A2"],
  "destination_names": ["B1", "B2", "B3"],
  "supply": [100, 150],
  "demand": [80, 90, 80],
  "costs": [
    [4, 6, 8],
    [5, 3, 7]
  ]
}
```

## Вариант 17

Файл `lab4_example.json` задает закрытую транспортную задачу 5 x 5. Суммарные запасы и потребности равны 2100, поэтому фиктивный поставщик или потребитель не добавляется.

Оптимальный план программы:

| Поставщик | B1 | B2 | B3 | B4 | B5 |
|---|---:|---:|---:|---:|---:|
| A1 | 300 | 300 | 0 | 300 | 0 |
| A2 | 0 | 0 | 100 | 0 | 0 |
| A3 | 0 | 0 | 100 | 0 | 0 |
| A4 | 0 | 0 | 0 | 200 | 400 |
| A5 | 200 | 0 | 200 | 0 | 0 |

Минимальная стоимость перевозок:

```text
7100
```
