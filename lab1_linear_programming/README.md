# ЛР1. Решение задач линейного программирования

Модуль решает двумерные задачи линейного программирования графическим методом.

## Что делает программа

1. читает математическую модель из JSON;
2. строит ограничения и область допустимых решений;
3. находит угловые точки области;
4. вычисляет значение целевой функции в каждой угловой точке;
5. выбирает оптимальную точку;
6. сохраняет Markdown-отчет и PNG-график.

## Вариант 17

Исходная задача содержит три изделия:

- `x1` — телевизоры;
- `x2` — стереосистемы;
- `y` — акустические системы.

Условие «спрос на стереосистемы в два раза выше, чем на акустические системы» используется как связь:

```text
x2 = 2y
```

Поэтому задача сводится к двум переменным `x1` и `y`:

```text
F = 75x1 + 135y -> max

x1 <= 250
2x1 + 5y <= 800
x1 + 2y <= 450
2x1 + 3y <= 600
x1 >= 0, y >= 0
```

## Запуск

Из корня проекта:

```bash
python main.py -n 1 -i lab1_example.json -o results/lab1.md
```

Из каталога лабораторной:

```bash
python main.py -i examples/lab1_example.json -s ../results/lab1.md
```

## Результат варианта 17

```text
x1 = 150
x2 = 200
y = 100
F = 24750
```

После запуска создаются:

- `results/lab1.md` — Markdown-отчет;
- `results/lab1.png` — графическая интерпретация решения.
